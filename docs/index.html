실전 운용과 검증을 한 흐름으로

단순 신호 발생기를 넘어 데이터 준비, 전략 검증, 포지션 실행과 청산 안전장치를 함께 제공합니다.

01 / ENTRY

3-TF 진입 엔진

의사결정·실행·트레일링 타임프레임을 분리해 신호 판단과 체결 대응을 정교하게 구성합니다.

02 / REGIME

시장 레짐 전략

Quiet, Normal, Trend, Panic 환경에 맞춰 전략과 위험 파라미터를 구분해 운용합니다.

03 / UNIVERSE

Dynamic Top N

거래대금 기반 종목군을 동적으로 갱신하고 선택된 시장 범위에서 후보를 추적합니다.

04 / VALIDATION

다단계 백테스트

Sweep, Validation, Walk-forward를 통해 과최적화를 경계하고 일반화 가능성을 점검합니다.

05 / RISK

리스크 기반 포지션

지갑, 손절 거리, 종목별 위험 비율을 바탕으로 포지션 크기를 계산합니다.

06 / EXIT

서버 Stop 안전장치

Binance 서버 측 STOP_MARKET과 로컬 모니터링을 함께 사용해 오프라인 상황에도 대비합니다.
